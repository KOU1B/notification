# Система мониторинга сервисов (URL/IP)

Проект состоит из двух частей:
1. **Бот и API (`bot/`)**: Телеграм-бот для управления и API для приема данных от монитора.
2. **Монитор (`monitor/`)**: Скрипт, который опрашивает сервисы и отправляет результат в API.

## Установка

1. Склонируйте репозиторий.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Настройте `config.yaml`:
   - `telegram.token`: Токен вашего бота.
   - `telegram.main_admin_id`: Ваш Telegram ID.
   - `api.token`: Произвольная строка-токен для связи бота и монитора.

## Запуск

### Запуск Бота и API:
```bash
python3 -m bot.main
```

### Запуск Монитора:
```bash
python3 -m monitor.main
```

## Использование
1. Напишите боту `/start`.
2. Добавьте бота в группу и напишите там `/register_group`.
3. В боте добавьте сервис, выбрав зарегистрированную группу.

## Системные требования
Для выполнения ICMP Ping монитору могут потребоваться права root или `cap_net_raw`:
```bash
sudo setcap cap_net_raw+ep $(readlink -f $(which python3))
```
